# Alpine Mod Loader

Alpine Mod Loader loads compatible Sea Power code mods on the Public Beta.

Download AlpineModLoaderSetup.exe from Releases. Close Sea Power, run the installer and choose Install. Setup finds your Steam installation and preserves compatible existing runtime files. If needed, use Browse to choose Sea Power.exe.

Launch Sea Power normally after setup finishes. Keep your existing gameplay mod subscriptions. Some mods also need their own beta updates.

To undo setup, run the installer again and choose Restore.

The installer download is required. A Workshop subscription cannot install files beside Sea Power.exe.

Original Alpine material is distributed under LICENSE.txt. Included runtime components retain their own licenses and source references, supplied by the installer.
